# CS50 Coursework Repository

This repository contains lecture notes, code samples, and problem set solutions for each week of Harvard's CS50 course. It is organized by week, following the curriculum structure of the course.

> 🛠️ **Note:** This repository is being updated frequently as I progress through the course.

## 📚 Course Overview

CS50 is Harvard University's introduction to the intellectual enterprises of computer science and the art of programming. This repository includes materials from:

- **Week 0** – Scratch  
- **Week 1** – C  
- **Week 2** – Arrays  
- **Week 3** – Algorithms  
- **Week 4** – Memory  
- **Week 5** – Data Structures  
- **Week 6** – Python  
- **Week 7** – SQL  
- **Week 8** – HTML, CSS, JavaScript  
- **Week 9** – Flask  
- **Week 10** – The End  

Each folder corresponds to a specific week and includes lecture notes (where applicable) and my solutions to the problem sets.

## 🚀 Getting Started

To explore the repository:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/cs50.git
   cd cs50

2. Navigate to the week you are interested in.

3. Open the code or run the solutions using your preferred environment.
    Note: Some files (e.g., C or Python programs) may require specific compilers or interpreters.
